# 📊 Econometría: Matriz Diferencial, Guía de Supuestos & Simulador de Examen

Aplicación web interactiva completa para el estudio de Econometría (desde MCO Simple hasta Series de Tiempo Asintóticas).

## 🚀 Enlaces de Acceso Inmediato
- **GitHub Pages:** [https://claudioarg.github.io/resumen-econometria/](https://claudioarg.github.io/resumen-econometria/)
- **Despliegue en Render (1-Click):** [Deploy to Render](https://render.com/deploy?repo=https://github.com/claudioarg/resumen-econometria)

## 📱 Características
- **100% Responsive:** Diseñado para teléfonos móviles y tablets.
- **Simulador de Parcial:** 176 preguntas (20 preguntas teóricas por cada una de las 8 unidades + ejercicios prácticos) con retroalimentación y desarrollo matemático paso a paso.
- **Demostración Numérica:** 10 ejercicios con números clickeables y popover de origen y fórmula.
- **Reconocimiento Visual:** Gráficos vectoriales interactivos para identificar patrones en 5 segundos.
- **Tablas Panorámicas:** Encabezados 2D fijos con selector de altura.
- **PDF de Estudio:** Incluye el resumen completo listo para imprimir.
